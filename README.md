# 単位のつながり帳

高校理科（物理・化学・生物・地学）で登場する単位を、**記号だけでなく単位どうしの関係として**つかむためのWebアプリです。単一のHTMLファイルで動きます。

👉 **[https://unit.meetupsensei.com/](https://unit.meetupsensei.com/)**

---

## つくった理由

単位は「N はニュートン」と記号を暗記して終わりになりがちですが、実際には

- N = kg・m/s²（運動方程式 F = ma そのもの）
- J = N・m = C・V（力学と電気が同じ単位でつながる）
- V = J/C（電圧はエネルギー ÷ 電気量）

というように、**式の構造がそのまま単位の構造になっています**。触りながらこのつながりを辿れれば、単位は覚えるものから確かめるものになります。教員が説明するのではなく、生徒が自分で気づく形を目指しました。

## 3つの使い方

### 1. 単位表

87の単位を分野別（基本単位／力学／熱／波・光／電磁気／原子／化学／生物／地学／天文）にタイル表示します。教科チップと検索で絞り込めます。

単位を選ぶと、1画面に次の流れが出ます。

```
何からできているか   →   その単位   →   何をつくれるか
    kg ・ m/s²              N            J ・ Pa ・ N·s ・ N/m …
```

式の中の単位はすべてタップで辿れるので、N → J → W → V → Ω と芋づる式に移動できます。あわせて次も表示します。

- SI基本単位での表記と次元記号 `[M L T⁻²]`
- 組み立て方が複数ある単位は、その全通り（J は4通り）
- 同じ次元をもつ単位（J と N·m、Hz と Bq、Gy と Sv、V/m と N/C）
- その単位が出てくる式、換算、ひとことメモ

### 2. くみたてる

単位をタップして分子・分母に入れると、SI基本単位での表記・次元・**その次元に名前のついた単位**がその場で出ます。

> kg × m/s × m/s → kg·m²/s² → **J（ジュール）**

「お題：この単位をつくってみよう」で N・J・W・Pa・C・V・Ω・F・T・Wb・H などを選ぶと、できた時点で正誤を判定します。

### 3. クイズ

10問・4択。3種類の問題が混ざって出ます。教科で絞り込めます。

| 種類 | 例 |
|------|-----|
| 記号を選ぶ | 「ジュール」（エネルギー）の記号は？ |
| 組み立て方を選ぶ | Ω を基本単位で表すと？ |
| かけ算・わり算 | N ÷ m² はどの単位？ |

## 収録範囲

学習指導要領「物理」「化学」「生物」「地学」に出てくる単位を中心に、87項目を収録しています。

| 分野 | 例 |
|------|-----|
| SI基本単位 | m, kg, s, A, K, mol, cd |
| 力学 | m/s², N, J, W, Pa, Hz, kg·m/s, N·s, N/m, rad, rad/s |
| 熱 | J/K, J/(kg·K), J/(mol·K), °C, cal, kWh |
| 電磁気 | C, V, V/m, Ω, Ω·m, F, T, Wb, H, A/m |
| 原子 | eV, u, Bq, Gy, Sv |
| 化学 | mol/L, g/mol, L/mol, mol/kg, kJ/mol, C/mol, atm, g/cm³, % |
| 生物 | μm, mmHg, mg/dL, kcal, ppm, lx |
| 地学 | hPa, Gal, km/h, au, 光年, pc, W/m², ‰ |

**pH・マグニチュード・震度・等級**は「単位ではない目盛り（対数や階級）」として区別して収録しています。SI接頭語（T〜p）の早見表もついています。

## 授業での使いどころ

- **導入の5分**：新しい単位が出てきたときに「これは何からできている？」を単位表で確認する
- **演習前**：答えの単位が合っているかを「くみたてる」で自分で検算させる
- **単元のまとめ**：クイズを教科で絞って出題し、できなかった単位を単位表で辿り直す
- **自習**：生徒が自分のスマホ・iPadから開いて触る（ログイン不要）

## 技術的なこと

- HTML・CSS・JavaScript の単一ファイル。ビルド不要、フレームワーク不要
- 外部依存は Google Fonts のみ（読み込めない環境でもシステムフォントで動作します）
- 単位の次元は、定義された組み立て方から**再帰的に自動計算**しています。`N` の定義を書けば `Pa = N/m²` の次元も自動で決まります
- ライト／ダークの両方に対応。スマホでは詳細がボトムシートで開きます
- データはコード内の `UNITS` 配列にまとまっています。単位を増やすときはここに1行足すだけです

### 単位を追加する

```js
{
  id:'J_K',                    // 一意のID
  sym:'J/K',                   // 表示記号（上付きは <sup> が使えます）
  name:'ジュール毎ケルビン',
  qty:'熱容量',                 // 何を表す量か
  kind:'derived',              // base / derived / nonsi / scale
  forms:[[['J',1],['K',-1]]],  // 組み立て方（複数書けます）
  subj:['物理','化学'],         // 先頭がタイルの色になります
  field:'熱',                   // 表示するグループ
  note:'物体全体の温度を 1 K 上げるのに必要な熱量。',
  formulas:['Q = CΔT']         // 任意
}
```

`forms` を書けば次元は自動計算されます。SI以外の単位で係数だけが違うもの（cal, eV など）は `forms` の代わりに `dim` と `conv` を書きます。

## 公開の手順

1. このリポジトリの `index.html` をそのまま使う
2. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` に設定
3. 1〜2分で `https://<ユーザー名>.github.io/<リポジトリ名>/` が開きます
