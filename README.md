# 単位のつながり帳

高校理科の単位が何からできていて、何をつくれるかをたどれる単位マップ

🔗 **公開URL**: https://unit.meetupsensei.com/

## 概要

高校理科（物理・化学・生物・地学）に出てくる単位を一覧できるインタラクティブな単位表です。
単位をひとつ選ぶと、その単位がどの単位からできているか、どんな単位をつくれるかが見えます。
単位をかけ算・わり算で組み立ててSI基本単位に分解したり、クイズでお題の単位をつくったりできます。
k・m・μ などの接頭語の早見表もついています。

## 使い方

- 「単位表」で教科を絞り込んだり検索したりして、単位をタップすると詳細が見られます
- 「くみたてる」では、かける／わるを選んで単位を入れると、SI基本単位での表し方が表示されます
- 「クイズ」では、お題の単位を組み立ててみましょう
- ◐ ボタンでライト／ダークを切り替えられます
